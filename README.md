# 🧪 Rick and Morty — Android-приложение

Клиент для [The Rick and Morty API](https://rickandmortyapi.com), демонстрирующий современный подход к разработке Android-приложений.  
Позволяет просматривать персонажей вселенной, фильтровать их по множеству параметров и добавлять в избранное.  
Приложение работает **как онлайн, так и офлайн**.

---

## 🚀 Технологический стек

- **Язык:** Kotlin
- **UI:** Jetpack Compose
- **Архитектура:** Clean Architecture (UI → ViewModel → Interactor → Repository → Data Sources)
- **Асинхронность:** Kotlin Coroutines + Flow
- **Пагинация:** Paging 3
- **Сеть:** Retrofit 2 + OkHttp 3
- **База данных:** Room
- **Внедрение зависимостей:** Koin

---

## ✨ Ключевые особенности

Это не просто «ещё одно приложение».  
Здесь реализованы продуманные и элегантные решения для множества нетривиальных задач.

### 🔁 1. Бесконечная прокрутка и «умное» кеширование

- **Пагинация:** плавная бесконечная прокрутка через Paging 3.
- **Offline-first:** данные кешируются в Room, и приложение продолжает работать без интернета.
- **RemoteMediator:** управляет синхронизацией между сетью и локальной базой.
- **Интеллектуальное слияние:** новые данные не перезаписывают старые, а объединяются с ними — например, избранные персонажи не теряются после обновления.

---

### 🎯 2. Продвинутая система фильтрации

Отдельный экран фильтров позволяет комбинировать параметры для точного поиска:

- Только избранные
- **Статус:** Жив / Мёртв / Неизвестно
- **Пол:** Мужской / Женский / Бесполый / Неизвестно
- **Раса:** выбор из популярных (Human, Alien и др.) или ввод вручную
- **Тип:** свободное текстовое поле

---

### ❤️ 3. Избранное

- Любого персонажа можно добавить в избранное.
- Выбор сохраняется между сессиями.
- **Оптимистичный UI:** иконка «сердце» меняется мгновенно, создавая эффект быстрого отклика, пока запись сохраняется в фоне.

---

### 🌍 4. Полная русская локализация

- Полный перевод интерфейса и данных.
- **Гендерно-зависимая локализация:**
    - Мужские персонажи: *Жив / Мёртв*
    - Женские: *Жива / Мертва*
    - Бесполые: *Живо / Мертво*  
      Такой уровень внимания к деталям делает интерфейс естественным и аккуратным.

---

## 🏛️ Архитектура

- **Clean Architecture:** чёткое разделение слоёв (UI, Domain, Data) делает проект масштабируемым и тестируемым.
- **Interactor (Use Case):** изолирует бизнес-логику и упрощает ViewModel.
- **Два режима работы:**
-   загрузка данных из сети через RemoteMediator
-   чтение только из Room  
      ViewModel автоматически выбирает нужный сценарий в зависимости от статуса сети.
